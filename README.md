# checktoken

Check encode/decode helpers for token payloads in pipelines.

**Site:** https://theworker02.github.io/checktoken/

## Install / run

```bash
git clone https://github.com/theworker02/checktoken.git
cd checktoken
node src/cli.js
node --test
```
